# Oficjalne źródła

Sprawdzone przy przygotowaniu dokumentacji 16 września 2026. Przed wysyłką ponownie sprawdzić aktualność regulaminów, SDK i formularzy. Numery punktów i interfejs App Store Connect mogą się zmieniać.

| Źródło | Zastosowanie |
|---|---|
| [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/) | Integracje, branding, prywatność, logowanie i dostęp do recenzji |
| [App Review](https://developer.apple.com/app-store/review/) | Wyjaśnienia i przygotowanie dowodów |
| [OAuth 2.0 Policies Google](https://developers.google.com/identity/protocols/oauth2/policies) | Tożsamość klienta i ograniczenia osadzonego logowania |
| [Find Hub partner integration](https://developers.google.com/nearby/fast-pair/landing-page-find-hub) | Program akcesoriów, nie potwierdzenie praw klienta iOS |
| [Find Hub accessory specification](https://developers.google.com/nearby/fast-pair/specifications/extensions/fmdn) | Kontekst protokołu i zabezpieczeń akcesoriów |
| [GNU FAQ: TranslateCode](https://www.gnu.org/licenses/gpl-faq.html#TranslateCode) | Licencje a port na inny język |
| [Required reason API](https://developer.apple.com/documentation/bundleresources/describing-use-of-required-reason-api) | Manifest własnych API i zależności |
| [App Privacy Details](https://developer.apple.com/app-store/app-privacy-details/) | Definicje zbierania danych i deklaracje |
| [Usuwanie kont](https://developer.apple.com/support/offering-account-deletion-in-your-app/) | Zakres wymagań po dodaniu konta produktu |

| [External testers](https://developer.apple.com/help/app-store-connect/test-a-beta-version/invite-external-testers/) | TestFlight i beta review |
| [Submit an app](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/submit-an-app) | Końcowa wysyłka do recenzji |

Podstawą stwierdzeń o implementacji jest kod kopii i zapis SHA-256 oryginału, nie opis marketingowy. Brak znalezionego publicznego API nie jest dowodem, że Google nigdy nie udostępni ścieżki partnerskiej — to konkretna niewiadoma do rozstrzygnięcia.
